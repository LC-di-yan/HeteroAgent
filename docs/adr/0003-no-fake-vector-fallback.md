# 0003. 禁止伪向量降级

- 状态：已接受
- 日期：2026-11-06
- 相关：`memory/long_term.py`，缺陷 G7，方案 T-P0-05

## 背景

原实现中，embedding API 不可用时用 `sha256 → np.random.seed → randn` 生成"向量"继续检索。
这不会报错，但检索结果等同于随机，且会污染 RRF 融合与置信度判定。

## 决策

- embedding 不可用 → 抛 `EmbeddingUnavailableError`；
- 由启动期决定"拒绝启动"或"只读降级并在响应中显式标注检索不可用"；
- `ALLOW_EMBEDDING_FALLBACK` 只控制告警措辞，**不允许**生成伪向量；
- 所有检索结果的 `score` 必须归一化到 [0,1]，与置信度阈值同量纲。

## 后果

- 正面：故障可见；"看起来能用其实是随机"的隐性故障消失。
- 负面：无 key 环境无法演示检索；需要准备本地 embedding 兜底方案（bge-m3 等）。

## 备选方案

- 本地小模型兜底：方向正确，但属于 P2 的可选 Provider 实现，不影响本条决策。
