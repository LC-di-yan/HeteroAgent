# 0001. 保留固定 Supervisor 状态图，不做自主 Agent 循环

- 状态：已接受
- 日期：2026-11-06
- 相关：`agents/supervisor.py`，方案 0.2 节"分歧裁决"

## 背景

2025 年后主流 Agent 框架鼓励"自主循环"（模型自行决定下一步、自由调用工具、自我反思重试）。
本系统服务金融客服场景，一次错误回复可能构成合规事故。

## 决策

- 拓扑固定为 `路由 → 业务 Agent → 合规 → HITL 闸门 → 聚合`，节点顺序不可由模型改变；
- 重试是**有界**的：由框架 policy / 装饰器按异常类型决定，最多 N 次，不做"模型自己觉得该重试"；
- 工具调用（tool_calls）只发生在业务 Agent 内部，不能改变图结构。

## 后果

- 正面：每一步可审计、可回放；延迟上界可估算；合规节点无法被绕过。
- 负面：灵活性低，遇到新业务需要改图；不适合开放式任务。
- 重新评估条件：出现明确的多步开放式任务（如自动对账、跨系统流程编排），且业务方接受不确定性。

## 备选方案

- 全自主循环：灵活但不可预测，合规风险不可接受。
- 纯 workflow 引擎（无 LLM 决策）：无法处理自然语言诉求。
